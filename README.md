# AI Engineering Portfolio

**Live: [ai-eng-porto.vercel.app](https://ai-eng-porto.vercel.app)**

Portfolio site of Muhamad Syamsul Huda — Senior AI Engineer. Production LLM agents, RAG systems, and the Go backends underneath them.

## Featured work

- **The Trading Floor** — multi-agent AI council: 5 specialized agents (Quant, Sentiment, Macro, Risk, Chief) debate and reach consensus on stock decisions, streamed live via SSE
- **MCP-gRPC Bridge** — dynamic MCP server that auto-discovers gRPC microservices and exposes their methods as AI-callable tools with access control and JSON Schema generation
- **Production AI Assistant Backend** — Go, hexagonal architecture, multi-provider LLM routing, MQTT, deployed in production with CI/CD quality gates
- **RAG System (MTA AI)** — full-stack RAG: PDF ingestion, vector embeddings, chat with source citations
- **Vector DB Evaluation** — Qdrant vs ChromaDB vs pgvector benchmarked on real product-search workloads

## Stack

Next.js 14, TypeScript, Tailwind CSS. Content lives in `data/*.ts`; components in `components/`.

## Run locally

```bash
npm install
npm run dev
```
